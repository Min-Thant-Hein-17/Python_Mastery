# Problem: Analyzing Earthquake Impact Data

A recent earthquake affected multiple regions, and the government wants to analyze the impact to prioritize aid distribution. You are provided with the following data:

* **Regions:** `['Region A', 'Region B', 'Region C', 'Region D', 'Region E']`
* **Magnitude of Earthquake:** `[5.4, 6.1, 7.2, 4.8, 6.5]` (Richter scale)
* **Population Affected:** `[12000, 45000, 78000, 5000, 62000]`
* **Relief Supplies Sent (in tons):** `[10, 50, 70, 5, 60]`

Using this data, perform the following tasks:

## Tasks

### 1. Scatter Plot:
* Create a scatter plot with earthquake magnitude on the x-axis and population affected on the y-axis.
* Label the points with their corresponding region names.
* Add gridlines to the plot.

### 2. Bar Chart:
* Create a bar chart to compare the relief supplies sent to each region.
* Add different colors to each bar.
* Label the x-axis as Regions and the y-axis as Relief Supplies (tons).
* Add value labels above each bar.

### 3. Insights:
* Identify regions with the highest population affected and the lowest relief supplies sent.
* Add annotations to your plots to highlight these regions.

### 4. Customization:
* Add meaningful titles, legends (where applicable), and adjust font sizes for readability.
