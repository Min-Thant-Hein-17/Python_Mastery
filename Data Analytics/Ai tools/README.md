# Ai tools for Data Analytics 

Source: https://lnkd.in/p/gJZr2FUc 

→ SQL assistance: Use ChatGPT or GitHub Copilot to draft queries and explain joins. Check the logic before trusting the result.

→ Data cleaning: Use tools like Power Query Copilot or Julius AI to find gaps, duplicates, and inconsistent labels. You decide how to handle them.

→ Analysis: Explore trends with Hex Magic or Databricks AI/BI Genie. Ask what supports each suggested finding.

→ Visualization: Create a first chart with Power BI Copilot or Tableau Agent, then make sure it answers the actual business question.

→ Reporting: Turn repeatable analysis into clearer updates with Rows AI or Microsoft Fabric Copilot. Verify every number before it goes out.

→ Coding: Let Cursor or GitHub Copilot speed up Python scripts and notebooks. Run the code, inspect the output, and fix what fails.
