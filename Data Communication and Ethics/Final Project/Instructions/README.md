# Project Instructions

Project submission deadline - May 25th 2026
Presentation Day - May 25th, 27th, 28th 2026 (Schedule - TBA)
1. Project Overview
In this final project, you will transform a personal story into a data-driven, interactive dashboard that supports decision-making while demonstrating ethical data practices.
This project is designed to help you:
Turn real-life experiences into structured data
Communicate insights using visualization
Make decisions based on data
Apply ethical thinking in data communication
 2. Project Objectives
By completing this project, you should be able to:
Design a meaningful dataset from a real-life context
Perform exploratory data analysis (EDA)
Build an interactive dashboard
Answer decision-making questions using data
Identify ethical risks and limitations in your data
Communicate insights clearly and responsibly

 3. Project Topic (Choose ONE)
You must choose one personal story:
Option A: Person I Admire
Example:
Parent, teacher, mentor, or public figure
Analyze their habits, journey, or impact

Option B: A Life Event I Will Never Forget
Example:
Academic success/failure
Moving to a new place
Personal challenge

Option C: My Growth Journey
Example:
Learning programming
Fitness journey
Academic improvement
Option D: Any personal story you’d like to share

 4. Dataset Requirements
You must create your own dataset.
Important Rules:
Do NOT include sensitive personal information (real names, private details)
You must anonymize all third-party data
You must clearly define all variables

 5. Exploratory Data Analysis (EDA)
You must explore your dataset and answer questions such as:
What patterns do you observe over time?
What factors influence outcomes?
What are the best and worst moments?
Are there any relationships between variables?
⚠️ You must decide:
Which visualizations to use
How to present your findings

6. Dashboard Requirements
You must build an interactive dashboard using one of the following:
Streamlit
Tableau
Power BI
D3.js
 Required Dashboard Components
Your dashboard must include:
1. 📖 Story Overview
Explain your story clearly
Why is it meaningful?

2. 📊 Data Visualizations
At least 4 visualizations
Must be clear and well-labeled
Must support your analysis

3. 🔍 Key Insights
Highlight important findings
Explain what the data shows
4. 🎯 Decision-Making Section
Answer:
“Based on my data, what should I do differently in the future?”
Must be supported by data
Must not overclaim

5. ⚖️ Ethics & Responsibility Section (MANDATORY)
You must include all of the following inside your dashboard:
🔒 Privacy Statement
What data is included?
What is anonymized?

⚠️ Bias & Limitation Disclosure
Examples:
Memory bias
Small dataset
Subjective scoring

📊 Visualization Justification
Explain:
Why you chose each chart
Any risk of misinterpretation
🎯 Responsible Decision
Include limitations of your decision
6. 🎛️ Interactivity
Include filters (e.g., time, category)
Users must be able to explore the data

📦 7. Deliverables
You must submit:
1. Dataset (CSV)

Publicly available hosted link 

3. Report (2–3 pages)
Include:
Story description

Ethical discussion
4. Presentation Slides
